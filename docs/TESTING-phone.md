# בדיקת הגישה מהטלפון (למי שעוזר לבדוק)

תודה שאתם בודקים! זה לוקח בערך 15 דקות. צריך מחשב **Windows 10 או 11** וטלפון.
את הממצאים כותבים ב-[Issues](../../../issues) של הפרויקט, עם צילום מסך אם אפשר.

## במחשב

1. מורידים את **`WhatsApp-Summary-Setup-0.3.0-beta.1.exe`** מ[דף הגרסה](../../../releases/tag/v0.3.0-beta.1), מתקינים ופותחים את התוכנה.
   אם מופיע "Windows protected your PC": **More info** ← **Run anyway** (התוכנה לא חתומה דיגיטלית).
2. הגדרות ← **גישה מהטלפון** ← **"📱 הפעל גישה מהאפליקציה"**.
   - [ ] אחרי כמה שניות כתוב **🟢 פועל ומוכן לחיבור מכל מקום**.
   - [ ] אם Windows שאל על גישה לרשת עבור `p2p-bridge`: מה בחרתם? (כתבו את זה בממצאים.)
3. לוחצים **"➕ צמד טלפון חדש"**.
   - [ ] מופיע קוד QR, ומתחתיו ספירה לאחור של 2 דקות.

## בטלפון

> אם האפליקציה עוד לא זמינה לכם, אפשר לבדוק את החלק של המחשב בלבד, או לבנות אותה לפי [mobile/README.md](../mobile/README.md).

4. פותחים את האפליקציה ← **"📷 סרוק קוד QR מהמחשב"** ← מאשרים מצלמה ← סורקים.
   - [ ] האפליקציה נפתחת ישר למסך הראשי של התוכנה.
   - [ ] במחשב, ברשימה, הטלפון מופיע עם **מחובר**.
5. מעבירים את הטלפון לרשת סלולרית (מכבים Wi-Fi) ומרעננים.
   - [ ] התוכנה עדיין עובדת.
6. סוגרים את התוכנה במחשב (לחיצה ימנית על האייקון ליד השעון ← **יציאה (עוצר גם את הבוט)**).
   - [ ] בטלפון מופיע **"המחשב לא זמין כרגע — מנסה להתחבר מחדש..."**.
   - [ ] פותחים שוב את התוכנה במחשב: אחרי עד חצי דקה (או בלחיצה על **"נסה שוב"**) הטלפון מתחבר שוב לבד.
7. בטלפון, פותחים את **הגדרות** של התוכנה ומנסים לשנות משהו בלשונית **ספקי AI בענן**.
   - [ ] מופיעה הודעה **"אפשר לשנות את זה רק במחשב עצמו"** (ככה זה אמור להיות).
8. במחשב, ליד הטלפון ברשימה, לוחצים **"בטל"**.
   - [ ] בטלפון מופיע **"המחשב ביטל את הגישה של הטלפון הזה"**.

## מה לכתוב בממצאים

- גרסת Windows, דגם הטלפון, ומה הייתה הרשת (בית, עבודה, סלולר).
- כל שלב שלא עבד: מה ציפיתם ומה קרה.
- אם משהו נתקע: הקובץ `logs\engine-stdio.log` מתיקיית הנתונים (הגדרות ← מצב מערכת ← "פתח את תיקיית הנתונים").
