חיבור לוואטסאפ

התוכנה מתחברת לוואטסאפ שלך כ"מכשיר מקושר" וקוראת בלבד. היא לא שולחת הודעות. הכול נשמר במחשב הזה.

  1. פתח את וואטסאפ בטלפון.
  2. הגדרות (או ⋮) › מכשירים מקושרים › קישור מכשיר.
  3. לחץ "קישור באמצעות מספר טלפון במקום זאת".
  4. הקלד את הקוד שמופיע כאן.
הקוד תקף לזמן קצר. ממתין לאישור מהטלפון…
✓

מחובר. מוריד את היסטוריית השיחות מהטלפון.

וואטסאפ שולח את ההיסטוריה פעם אחת בלבד. השאר את התוכנה פתוחה ואת הטלפון מחובר לאינטרנט עד שהמספר מפסיק לעלות.

הבוט רץ עם גרסה ישנה. הפעל אותו מחדש (restart-bot.bat) כדי שהעדכונים יעבדו.
